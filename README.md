# 🎮 Tic-Tac-Toe Game (VOSC Activity-1)

A clean, modern, and interactive Tic-Tac-Toe web game built using HTML, CSS, and Vanilla JavaScript.

---

## 🌟 Features

- 👥 **2-Player Mode**: Play locally with a friend taking turns.
- 🎨 **Modern & Sleek UI**: Polished glassmorphism design with smooth hover effects.
- 🏆 **Win & Draw Detection**: Automatically highlights winning lines and announces game results.
- 🔄 **Restart Button**: Reset the board anytime to start a fresh match.
- 📱 **Responsive Design**: Works seamlessly on mobile, tablet, and desktop screens.

---

## 🕹️ How to Play

1. **Player X** starts first.
2. Click on any empty cell on the 3x3 grid to place your mark.
3. Players take turns alternating between **X** and **O**.
4. The first player to align **3 symbols** in a row (horizontal, vertical, or diagonal) wins!
5. If all 9 cells are filled without a winner, the match ends in a **Draw**.
6. Click the **Restart Game** button to play again.
